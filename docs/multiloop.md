# 멀티 이벤트 루프 결정 기록

## 결정 (M, 2026-11-25)

| # | 결정 | 대가 / 남는 구멍 |
|---|---|---|
| M1 | 루프마다 같은 포트로 listen 소켓을 열고 SO_REUSEPORT로 커널이 연결을 나눔. accept 전담 스레드는 만들지 않음 | 커널이 해시로 고정 배정해서 한 루프에 몰려도 옮길 수 없음. macOS는 분배 보장 안 됨 → M2 |
| M2 | 루프 수 기본값 sysconf(_SC_NPROCESSORS_ONLN), --loops N(1~256, 벗어나면 사용법 출력 후 종료 코드 2)으로 덮어씀. macOS(__APPLE__) 빌드는 기본 1. 시작 로그에 루프 수 | docker run --cpus 제한은 sysconf에 안 보임 → README에 --loops로 맞추라고 적음 |
| M3 | buffer.c 메모리 합계(NET-12 512MB)는 C11 원자 변수 하나를 모든 루프가 같이 셈. 먼저 atomic_fetch_add, 상한을 넘으면 atomic_fetch_sub로 되돌리고 실패 | 버퍼를 늘릴 때마다 원자 연산 1번 |
| M4 | 최대 연결 수는 서버 전체 합계를 원자 변수로 셈 (M3과 같은 방식). 각 루프는 "전체가 찼나"만 보고 accept를 멈추고, resume_accepting에서 다시 받음. raise_fd_limit은 시작 때 한 번, 전체 기준 | 연결을 받을 때·닫을 때 원자 연산 1번 |
| M5 | upstream_t(Round-Robin 차례, 빠진 시각)는 루프마다 따로 만듦. 공유 안 함 | 전체 순서가 정확히 번갈아 가진 않음. 한 루프가 뺀 백엔드를 다른 루프는 모름 → 루프마다 첫 실패를 한 번씩 겪음 |
| M6 | 종료: 핸들러는 그대로 두고 shutdown_flag를 volatile sig_atomic_t에서 atomic_int로 바꿈. 각 루프는 WAIT_MAX_MS(1초) 안에 깨어나 확인하고 자기 listen 소켓을 닫고 기존 종료 절차를 밟음. 메인 스레드는 루프 스레드를 만들고 pthread_join으로 모두 기다린 뒤 server_t들 → 설정 순서로 정리 | 루프마다 종료 시작이 최대 1초 어긋남 (최대 약 6초, docker stop 10초 안). 닫은 listen 소켓 대기열의 연결은 끊김 |
| M7 | 루프끼리 같이 쓰는 쓰기 값은 M3·M4·M6 세 개뿐. 설정(proxy_config), 루트 경로, 로그 레벨은 스레드를 만들기 전에 정하고 읽기만 함. 연결 하나는 자기를 받은 루프만 만짐 (루프 사이에 연결을 넘기지 않음) | — |
| M8 | 검증: 기존 테스트는 고치지 않고 기본 루프 수(코어 수)로 그대로 통과. Makefile에 tsan, tsan-test 추가 (asan-test와 같은 모양, 보고가 하나라도 있으면 실패). 새 테스트 파일 tests/multiloop_test.py에 ML-1~3 | TSan은 ASan과 같이 못 켬 → 빌드 하나 추가 |
| M9 | (2026-11-25 추가) 루프 하나마다 고정 fd가 4개(listen, epoll, 루트, 비상용) 늘어서, 기존 테스트의 fd 절대 기준(≤ 12, 상한 + 30, fd 고갈 시험의 한도 48)에 `4 × (루프 수 − 1)`을 더한다. 루프 수는 테스트가 기본값과 같은 방법으로 셈(macOS 1, Linux `os.cpu_count()`). 다른 기대값은 그대로 | 확정된 테스트 파일의 숫자를 고침. 대신 기존 테스트 전부가 기본 루프 수로 돎 |

## 새 테스트 (ML)

| ID | 상황 | 기대 결과 | 결정 |
|---|---|---|---|
| ML-1 | --loops 4로 시작 | 시작 로그에 루프 4개, 정적·프록시 요청 정상 | M1, M2 |
| ML-2 | --loops 4 --max-connections 4 + 연결 5개 | 4개만 받고 5번째는 기다림. 하나를 닫으면 5번째를 받음 | M4 |
| ML-3 | --loops 4 + 여러 연결에 처리 중 요청을 걸어 둔 채 SIGINT | 처리 중 요청이 모두 끝난 뒤 종료, 종료 코드 0, 7초 안 | M6 |
